  - UDP 에코 서버 및 클라이언트 프로그램을 작성했을 때, TCP 기반 프로그램과의 차이점

## 2

- 한 번에 하나의 클라이언트와 통신 가능한 서버 및 클라이언트 프로그램을 작성하시오.
- 통신은 TCP와 UDP 두 가지를 기반으로 동작한다.
- 클라이언트는 서버에게 다음과 같은 속도로 데이터를 전송한다.
  - 초당 500 bytes, 1000 bytes, 2000 bytes
- 서버는 데이터를 수신 후 삭제한다.
- 클라이언트와 서버 간 RTT는 100ms이고 클라이언트와 서버 간 패킷 손실률은 0.1%, 1% 로 설정한다.
- 해당 기능은 NetEM과 같은 네트워크 에뮬레이터를 사용한다.
- 작성한 프로그램에 대해 아래의 내용을 보고서로 작성하시오.
  - 전송 속도 변화에 따른 클라이언트와 서버 간 throughput 측정 및 변화
  - 패킷 손실률 변화에 따른 클라이언트와 서버 간 throughput 측정 및 변화
  - 위 내용에서 TCP와 UDP 간 차이점
